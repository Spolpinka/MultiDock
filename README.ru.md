# MultiDock

**Несколько прозрачных доков для macOS: на любых краях экрана одновременно.**

В macOS один Dock и на одном краю. MultiDock добавляет сколько угодно дополнительных доков (слева, справа, сверху, снизу), у каждого свои приложения, форма и стиль. Системный Dock остаётся как есть.

## Возможности

- Несколько доков на разных краях экрана **одновременно**
- Матовое стекло с настраиваемой прозрачностью
- Формы: прямоугольник, квадрат (сеткой) или овал
- Размер иконок, отступ внутри и граница настраиваются
- Док можно перетащить мышкой: он прилипнет к ближайшему краю, перестроится в горизонтальный или вертикальный и **запомнит место** вдоль края
- Перетаскивание приложений из Finder и «Программ», перестановка иконок и перенос между доками
- Индикатор запущенных приложений, «Показать в Finder», запуск при входе
- Лёгкое нативное приложение на Swift/SwiftUI, для сборки не нужен Xcode

## Установка

**Скачать:** возьмите `MultiDock.zip` в разделе [Releases](../../releases), распакуйте и перенесите `MultiDock.app` в «Программы».

Приложение не нотаризовано, поэтому при первом запуске macOS может его заблокировать. Нажмите правой кнопкой → **Открыть** или выполните:

```
xattr -dr com.apple.quarantine /Applications/MultiDock.app
```

**Сборка из исходников** (нужны только Command Line Tools):

```
xcode-select --install   # если ещё не установлены
git clone https://github.com/Spolpinka/MultiDock.git
cd MultiDock
bash build.sh
open MultiDock.app
```

Нужна macOS 13 или новее.

## Использование

- Правый клик по фону дока → **Доки по краям экрана**: включайте доки снизу, слева, справа, сверху. Новый док копирует стиль первого видимого.
- Тяните док за свободное место рамки, чтобы перенести на другой край.
- Правый клик по фону дока: добавить приложение, вернуть в центр края, форма, граница, отступ, размер иконок, плотность стекла, применить стиль ко всем докам, скрыть, удалить, выйти.
- Правый клик по иконке: показать в Finder / убрать из дока.
- Те же переключатели есть в иконке в строке меню.
- Настройки хранятся в `~/Library/Application Support/MultiDock/config.json`.
